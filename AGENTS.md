# AGENTS.md

Instructions for coding agents (Codex, Cursor, Copilot, Jules, Claude and
others) live in [CLAUDE.md](CLAUDE.md) and the path-scoped rules in
[`.claude/rules/`](.claude/rules/). Read CLAUDE.md in full before making
changes, starting with **Architecture boundaries**: it links the ADRs in
[`docs/adrs/`](docs/adrs/README.md) that a change must not contradict without a
new ADR. Pull request expectations are in [CONTRIBUTING.md](CONTRIBUTING.md).
